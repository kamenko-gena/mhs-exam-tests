**Тесты по вопросам технического облуживания, монтажа, наладки пожарной автоматики**

### Режимы
- Проверка знаний - все вопросы по теме
- Экзамен - 10 вопросов с правом на две ошибки (вопросы можно пропускать)

### Функционал
- Продолжение работы после закрытия вкладки/браузера
- Переходы по вопросам: вперед-назад, по введенному номеру вопроса
- Возможность перемешать вопросы
